📄

Markdown + PDF

Genera book.md con todo el contenido y opcionalmente book.pdf con tipografía limpia, código resaltado y números de página.

♻️

Resume automático

El estado se guarda tras cada página en state.json. Si el proceso se interrumpe, al volver retoma exactamente donde quedó.

🖼️

Imágenes locales

Todas las imágenes se descargan y referencian con rutas relativas. El resultado es una carpeta auto-contenida que funciona sin internet.

🌐

Soporte JavaScript

Flag --js activa Playwright para sitios que renderizan con JS: GitBook moderno, MkDocs Material, Docusaurus.

🔌

API REST + SSE

FastAPI con jobs en background y progreso en tiempo real vía Server-Sent Events. Descarga el libro como ZIP al finalizar.

🔍

Detección automática

Detecta la plataforma (Sphinx, GitBook, MkDocs, Docusaurus) y aplica selectores CSS específicos para extraer el índice y el contenido.

Listo en
dos minutos

Crea el entorno virtual, instala dependencias y convierte tu primera documentación.

01 Clona el repo y entra al directorio
02 Ejecuta make install — crea .venv/ e instala todo
03 Para sitios JS: make install-js (instala Playwright)
04 Convierte: make convert-pdf URL=https://...
05 O levanta la API: make dev
Makefile targets docs2book/ 
# Setup
make install
make install-js        # + Playwright

# Convertir
make convert           # → Markdown
make convert-pdf       # → Markdown + PDF
make convert-js        # → JS + Markdown
make convert-js-pdf    # → JS + MD + PDF

# API
make dev               # localhost:8000
make start             # producción

# Con variables
make convert-pdf URL=https://docs.docker.com/ \
                 OUTPUT=docker_book

Cada conversión genera una carpeta auto-contenida: el índice, el libro completo, imágenes locales y páginas individuales ordenadas.

Con --pdf se agrega book.pdf con tipografía limpia, bloques de código con fondo oscuro y numeración de páginas.
